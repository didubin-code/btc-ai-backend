# BTC AI Backend v69.1 — Raw-Market-First Independent AI

This backend forces the AI to form an independent decision from raw venue/price/timer/target/cost data first, then compare that read against the deterministic dashboard engine.

Endpoints:
- `GET /health`
- `POST /analyze`
- `POST /api/ai-review`

Render:
- Build command: `npm install`
- Start command: `npm start`
- Env var: `OPENAI_API_KEY`
